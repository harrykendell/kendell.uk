kendell.uk Home development access

Set up this computer

Configure a Linux or macOS computer for authenticated SSH and VS Code Remote-SSH access to the Kendell home development machine.

Installer

The installer adds Cloudflare's SSH client, configures ssh.kendell.uk, and installs VS Code Remote-SSH when VS Code is available.

Download installer
  1. Download the installer.
  2. Open a terminal in your Downloads folder.
  3. Run the command below. The first SSH connection will open Cloudflare Access in your browser.
chmod +x kendell-home-ssh-install.sh ./kendell-home-ssh-install.sh

After setup

Use the same hostname for both a normal shell and VS Code.

Terminal
ssh ssh.kendell.uk
VS Code
Remote-SSH → Connect to Host… → ssh.kendell.uk
Thesis
/home/harry/Desktop/thesis
code --new-window --remote ssh-remote+ssh.kendell.uk /home/harry/Desktop/thesis

No SSH credential is embedded in this page or installer. Cloudflare Access still authenticates the connection to ssh.kendell.uk, and the home SSH service is not exposed directly to the Internet.
